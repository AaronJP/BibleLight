# BibleLight（亮光）圣经工具

## 💡 工具介绍

**解决问题**：阅读电子神学资料时，因查考经文思路被打断的问题  
**实现功能**：复制经文引用（35个字符以内），桌面弹窗显示经文内容，数秒后消失

## ⚙️ 系统托盘功能

- **设置**：可设置经文卡片窗的显示样式、字体、圣经版本、显示位置、显示时长
- **特别说明**：
  - 位置设置中的"自定义位置"开关打开，可拖拉卡片窗到任意合适位置，下次弹窗显示时将保持该位置
  - 时长设置中的"鼠标悬停暂停"开关打开，鼠标悬停在卡片窗上时，卡片窗不消失，直到鼠标移出卡片窗2秒后消失
- **帮助**：显示本文档内容

## 🛠️ 卡片窗操作说明

- 鼠标左键可拖拉卡片窗左边缘调整宽度
- 鼠标左键可拖拽卡片窗到合适位置
- 点击相应按钮可复制内容、固定卡片或关闭卡片窗

## 📖 支持的经文格式

### 标准格式
- **标准书卷名**：`创世记1:1`、`太1:1`
- **繁体书卷名**：`約翰福音1:1`、`詩23:6`
- **英文书卷名**：`John1:1`、`Ps 23:6`
- **个别不标准书卷名**：`以斯拉2：1`、`腓立比1:17`、`创世纪1:1`

### 中文数字格式
- **中文章数**：`约三16`、`诗篇第一百廿三篇二节`、`诗一百〇三11`、`創三9`

### 范围查询
- **范围查询**：`传道1:1-3`、`箴言一3~5`、`太5：3〜8`、`詩三4-5`、`詩三篇五節至六節`、`詩篇第1篇1至2節`、`LV4:1-3`

### 复合查询
不同书卷、不同章节的情况：
- `创1:1-2，二3,40:3`
- `罗马书1 章 16 节，3 章 10 至 20 节`
- `创1:1、5、10-12，申命记3:1-5,4:8，传道三1`
- `gn.1:1;lv3:3`

### 简化查询
- **只包含章节信息**（缺失书卷名）：正常查询过之后，90秒之内，复制章节信息，会按上次查询过的书卷来显示
  - `2:1-3`、`廿3`、`三：3`
- **只包含节信息**（缺失书卷和章）：正常查询过之后，90秒之内，复制节数字，会按上次查询过的书卷章来显示
  - `8节`、`12-13`、`3`

### 特殊书卷
- **只有一章的书卷**：`俄3`=`俄巴底亚书1:3`、`约翰叁书2`=`约翰三书1:2`、`约贰5`=`约翰二书1:5`
- **书卷章节错误的情况**：`创4`（只有章数没有节号）、`太1:28`（超出范围）

## ❌ 不支持的格式

- **跨章查询**：`创世记1:1-2:3`
- **整章查询**：`创世记1:`
