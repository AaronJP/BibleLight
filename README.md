# 欢迎使用BibleLight（亮光）圣经工具1.0.0

[演示视频](https://www.youtube.com/watch?v=2W1emPmBaJQ)

## 📜工具介绍  

- 受用群体：常常阅读神学资料的基督徒  
- 解决问题：阅读神学文献时，因查考经文思路被打断的问题  
- 实现功能：复制经文引用，桌面右下角弹窗显示经文内容，数秒后消失  

## 📄🛠️卡片窗操作说明  

- 可拖拉卡片窗宽度
- 可拖动卡片窗位置
- 点击相应按钮可复制内容、固定卡片或关闭卡片窗

## ⚙️ 系统托盘功能

- 样式选择：可选择五种不同风格的经文卡片样式
- 宽度设置：可选择设置卡片300-700px的宽度，或者鼠标拖拉宽度
- 字体大小：可选择设置卡片字体小（14px）、中(16px)、大(18px)  
- 卡片时长：设置卡片窗显示的持续时间（5-12秒）
- 帮助说明：显示本文档内容

## 📖支持的经文格式  

- 标准书卷名：创世记1:1、太1:1  
- 繁体书卷名：約翰福音1:1、詩23:6
- 个别不标准书卷名：以斯拉2：1、腓立比1:17、创世纪1:1
- 中文章数：约三16、诗篇第一百廿三篇二节、诗一百〇三11、申卅9
- 范围查询：传道1:1-3、箴言一3~5、太5：3〜8、詩三4-5、詩三篇五節至六節、詩篇第1篇1至2節
- 复合查询：如下不同书卷、不同章节的情况
    - 创1:1-2，二3,40:3
    - 罗马书1 章 16 节，3 章 10 至 20 节
    - 创1:1、5、10-12，申命记3:1-5,4:8，传道三1
- 只包含章节信息（缺失书卷名）：正常查询过之后，50秒之内，复制章节信息，会按上次查询过的书卷来显示
    - 2:1-3、廿3、三：3
- 只包含节信息（缺失书卷和章）：正常查询过之后，50秒之内，复制节数字，会按上次查询过的书卷章来显示
    - 8节、12-13、3
- 只有一章的书卷：俄巴底亚书3、约翰叁书2、约贰5
- 书卷章节错误的情况：创4、太1:28

## ❌ 不支持的格式：  

- 英文书卷名的查询
- 跨章查询
- 整章查询
