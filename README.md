# BibleLight 圣经工具

## 💡 工具介绍

- **解决问题**：阅读电子神学资料时，因查考经文思路被打断的问题
- **实现功能**：复制经文引用（35个字符以内），桌面弹窗显示经文内容，数秒后消失
- *注意：如果不小心复制了多余的标点符号或空格等，不影响显示经文内容*

## 🚀 3步快速上手
- **复制经文引用**：在您阅读的资料中，复制包含经文引用的文字（35个字符以内），如 `创世记1:1` 或 `约3:16`
- **查看经文弹窗**：桌面会自动弹出卡片窗显示经文内容
- **自动消失**：数秒后卡片窗自动消失，不打断您的阅读

## ⚙️ 系统托盘功能

- **设置**：可设置经文卡片窗的显示样式、字体、圣经版本、显示位置、显示时长
- **圣经版本**：
  - 21种圣经译本可供选择使用
  - 在已选译本列表中，点击任意译本前的空白区域，可快速将其设置为默认译本，或者选中译本后，点击鼠标右键，将其设置为默认译本
- **特别说明**：
  - 位置设置中的"自定义位置"开关打开，可拖拉卡片窗到任意合适位置，下次弹窗显示时将保持该位置
  - 时长设置中的"鼠标悬停暂停"开关打开，鼠标悬停在卡片窗上时，卡片窗不消失，直到鼠标移出卡片窗2秒后消失
- **帮助**：显示本文档内容

## 🛠️ 卡片窗操作说明

- 鼠标左键可拖拉卡片窗左边缘调整宽度
- 鼠标左键可拖拽卡片窗到合适位置
- 查询时，点击卡片窗左下角的圣经译本信息可快速切换译本（请先在圣经译本设置里，将所要切换译本添加到已选译本里）
- 点击相应按钮可复制内容、固定卡片或关闭卡片窗

## 📖 支持的经文格式

### 一、基本查询
- **单节查询**：`创世记1:1`、`太1:1`、`約翰福音1:1`、`詩23:6`、`John1:1`、`约三16`、`詩三9`、`创世纪1:1`、`诗篇第一百廿三篇二节`
- **范围查询**：`传道1:1-3`、`箴言一3~5`、`太5：3〜8`、`詩三4-5`、`詩三篇五節至六節`、`詩篇第1篇1至2節`、`LV4:1-3`
- **整章查询**：`创4：`、`路十`、`创世记第三章`
- **跨章查询**：`创世记1-3章`、`利未记四章4节至五章3节`、`太5~7章`、`路十章至十一章`、`创世记一至三章`

### 二、高级功能
- **复合查询**：用逗号、顿号或分号分隔多个章节
  - `创1:1-2，二3，40:3`
  - `罗马书1 章 16 节，3 章 10 至 20 节`
  - `创1:1、5、10-12，申命记3:1-5,4:8，传道三1`
  - `gn.1:1;lv3:3`
- **上下文智能查询（90秒内有效）**
  - **只包含章节**：查询过某书卷后，输入 `2:1-3`、`廿3`、`三：3`，自动使用上次的书卷
  - **只包含节数**：查询过某书卷某章后，输入 `8节`、`12-13`、`3`，自动使用上次的书卷和章
- **只有一章的特殊书卷**：`俄3`=`俄巴底亚书1:3`、`约翰叁书2`=`约翰三书1:2`、`约贰5`=`约翰二书1:5`

### 三、格式兼容性
- 支持简体、繁体、英文书卷名
- 支持阿拉伯数字和中文数字
- 支持不标准书卷名（如创世纪、以斯拉）
- 多余的标点符号或空格不影响查询
